## Added
- **Alerts card in Settings** (`AlertChannelsSection`): list of channels with delivery state and last failure reason, **Test**, **Pause / Resume**, **Edit**, **Delete** (confirm dialog), and a form to add a Telegram channel (name, target user id, bot token, events, enabled). The bot token is a write-only password field; when editing, blank keeps the saved token. Test failures are shown on the row, not as errors.
- `src/api/alerts.ts`: pure helpers (events, draft validation mirroring the Controller, delivery state).
- Endpoint functions `listAlertChannels`, `getAlertChannel`, `createAlertChannel`, `updateAlertChannel`, `deleteAlertChannel`, `testAlertChannel`; wire types `AlertChannel*`, `AlertEvent`, `AlertTestResult` in `schema.ts`.
